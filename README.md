# HackFlow

HackFlow - консольный прототип сервиса для организации хакатона. Проект
помогает регистрировать команды, связывать их со сдачами проектов, проверять
дедлайн, считать оценки жюри и формировать итоговую статистику.

## Предметная область

Предметная область проекта - проведение хакатонов: регистрация команд,
подготовка проектных работ, сдача решений, оценивание и подведение итогов.

## Основные классы

- `Team` - команда хакатона, список участников, статус регистрации и признак
  студенческой скидки.
- `Hackathon` - хакатон с настройками регистрации, дедлайном, проходным баллом
  и связанными объектами команд.
- `Submission` - сданный проект, связанный с объектом команды.

В классах реализованы `__init__`, атрибуты, методы поведения, `__str__`,
а также методы `from_data()` и `to_data()` для преобразования JSON-данных в
объекты и обратно.

## Что реализовано

- Сущности, которые раньше хранились как словари, оформлены отдельными классами.
- Хакатон связан с объектами команд.
- Сдача проекта связана с объектом команды.
- Перед созданием сдачи проверяется, что команда зарегистрирована на хакатон и
  не отменена.
- JSON-загрузка создает связанные объекты, а сохранение записывает простые
  данные с идентификаторами.
- Функции поиска, сортировки и статистики оставлены обычными функциями, потому
  что работают с коллекциями объектов.
- Тесты проверяют создание объектов, связи, поиск, сортировку, расчет взноса,
  статусы сдачи, финалистов, статистику и сохранение в JSON.

## Данные

В демонстрационных JSON-файлах представлены:

- 1 хакатон;
- 5 команд;
- 4 сдачи проектов.

Файл `data/submissions.json` хранит `team_id`, а при загрузке это поле
преобразуется в связь с объектом `Team`.
