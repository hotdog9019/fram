# HackFlow

## Назначение
HackFlow - сервис для организации и проведения хакатона. Приложение помогает принимать заявки команд, контролировать лимит мест, проверять дедлайны сдачи проектов и формировать предварительный статус проекта по оценкам.

## Целевая аудитория
Сервис предназначен для организаторов хакатонов, кураторов команд, участников и членов жюри.

## Предметная область
Предметная область проекта - проведение хакатонов: регистрация команд, подготовка проектных работ, сдача решений, оценивание и подведение итогов.

## Основные сущности
- Хакатон
- Команда
- Участник
- Проект
- Заявка
- Оценка жюри

## Основные функции
- Регистрация команды с учетом текущего лимита мест.
- Расчет организационного взноса для команды.
- Проверка статуса сдачи проекта относительно дедлайна.
- Расчет общего и среднего балла проекта.
- Формирование предварительного решения жюри по суммарной оценке.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и ролей;
- добавление личных кабинетов организатора, участника и жюри;
- разработка REST API;
- контейнеризация приложения;
- настройка CI/CD.

## Начальный сценарий
В первой версии реализован консольный сценарий для демонстрации базовой логики сервиса: проверяется возможность регистрации команды, рассчитывается взнос, определяется статус сдачи проекта, вычисляются баллы проекта и выводится предварительное решение жюри.
