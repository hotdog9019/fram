# Контрольные вопросы

## По материалам Яндекс Практикума

1. В Python используются типы `int`, `float`, `str`, `bool`, а также коллекции: списки, кортежи, словари и множества.
2. `int` хранит целые числа, `float` - дробные числа, `str` - строки, `bool` - логические значения `True` и `False`.
3. Преобразование типов используется, когда значение нужно привести к нужному типу, например строку `"4"` превратить в число `4`.
4. Со строками можно выполнять сложение, повторение, получение длины, форматирование, поиск и изменение регистра.
5. В Python используются операторы `==`, `!=`, `>`, `<`, `>=`, `<=`.
6. Конструкция `if` нужна для выполнения кода при выполнении условия.
7. `if` задает первое условие, `elif` проверяет дополнительные условия, `else` выполняется, если предыдущие условия ложны.
8. Составные условия записываются с помощью логических операторов `and`, `or`, `not`.
9. `and` требует истинности всех условий, `or` - хотя бы одного условия, `not` меняет логическое значение на противоположное.
10. Модуль Python - это файл или библиотека с готовым кодом, который можно подключить в программе.
11. `import` используется для подключения модуля.
12. Импорт модуля подключает весь модуль, а импорт отдельного объекта позволяет использовать конкретную функцию, класс или переменную.

## По рабочему окружению

13. Виртуальное окружение изолирует зависимости проекта от других Python-проектов.
14. IDE - среда разработки, в которой удобно писать, запускать и отлаживать код.
15. Git используется для контроля версий и сохранения истории изменений проекта.
16. Репозиторий - хранилище проекта и истории его изменений.
17. Commit - зафиксированное состояние проекта с сообщением об изменениях.
18. `.gitignore` нужен, чтобы исключить из Git временные файлы, окружения и служебные директории.
19. README.md нужен для описания назначения проекта, его функций и способа запуска.
20. Отладка - процесс пошаговой проверки программы и поиска ошибок.
21. Breakpoint - точка остановки программы во время отладки.
22. Пошаговое выполнение помогает увидеть, как меняются значения переменных и где появляется ошибка.
