## 3. Доработка индивидуального проекта

В рамках ПР5 консольный проект HackFlow подготовлен к переходу на Django.
Создан Django-проект `hackflow_site` и три Django-приложения:

- `homepage` - главная страница, общий HTML-каркас и обработчик 404;
- `teams` - страницы списка команд и отдельной команды;
- `submissions` - страницы списка проектов и отдельной сдачи.

Реализованные URL:

- `/` - главная страница проекта;
- `/teams/` - список команд;
- `/teams/<int:team_id>/` - карточка команды;
- `/submissions/` - список сданных проектов;
- `/submissions/<int:team_id>/` - карточка проекта команды;
- `/nonexistent/` и другие неизвестные адреса - пользовательская страница 404.

Веб-страницы формируются view-функциями и возвращаются через `HttpResponse`.
Для оформления используется HTML и Bootstrap 5.3. Навигация между основными
страницами вынесена в общую функцию `page()`.

Данные проекта продолжают загружаться из JSON-файлов ПР3:
`data/hackathon.json`, `data/teams.json`, `data/submissions.json`. Веб-слой
использует существующие классы `Hackathon`, `Team`, `Submission`, функции
загрузки данных, поиска, сортировки и расчета статистики.
