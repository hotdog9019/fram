# Контрольные вопросы ПР2

1. Основные коллекции Python: список, кортеж, множество и словарь. В проекте списки хранят команды и проекты, словари описывают одну команду, хакатон или заявку.
2. Список изменяемый, кортеж обычно используют для фиксированного набора значений.
3. Множество удобно для хранения уникальных значений и быстрой проверки наличия элемента.
4. Словарь хранит пары "ключ - значение", например `team["name"]`.
5. `for` используется для перебора коллекций, `while` выполняется, пока истинно условие.
6. `range()` создает последовательность чисел для циклов.
7. Словарь можно перебирать через `.items()`, `.keys()` или `.values()`.
8. `break` прерывает цикл, `continue` переходит к следующей итерации.
9. Функция объявляется через `def`; без `return` она возвращает `None`.
10. Позиционные параметры передаются по порядку, именованные - по имени.
11. Область видимости определяет, где доступна переменная.
12. Docstring документирует назначение функции, модуля или пакета.
13. Модуль Python - файл `.py` с кодом, который можно импортировать.
14. Импорт модуля подключает весь модуль, импорт объекта подключает конкретную функцию или значение.
15. Пакет - каталог с модулями; `__init__.py` обозначает пакет.
16. `try/except` нужен для обработки ошибок без аварийного завершения программы.
17. `else` выполняется при отсутствии исключения, `finally` выполняется всегда.
18. `raise` используется для явного создания исключения.
19. Файл нужно закрывать, чтобы освободить ресурс и корректно сохранить данные.
20. `with` автоматически закрывает файл после работы.
21. Интроспекция позволяет изучать объект во время выполнения через `type()`, `dir()`, `help()`.
22. Пространство имен связывает имена переменных и функций с объектами.
23. Итератор выдает элементы по одному, генератор создает значения по мере запроса.
24. `yield` возвращает значение из генератора и сохраняет состояние функции.
25. Lambda-функция - короткая анонимная функция; в проекте похожий подход используется в ключах сортировки.
26. Аннотации типов записываются в сигнатуре: `def load_json(path: str) -> Any`.
27. `flake8` проверяет стиль и типовые ошибки: `python -m flake8`.
28. Код должен быть читаемым, модульным, без дублирования, с понятными именами и корректным форматированием.
29. Pytest-тест - функция `test_*`, внутри которой проверки выполняются через `assert`.
30. Тесты запускаются командой `python -m pytest`; успешный результат показывает количество пройденных тестов.
31. В ПР2 реализованы регистрация, отмена заявки, поиск, сортировка, оценивание, статистика и работа с JSON.
32. Данные представлены списками и словарями, а сохраняются в JSON-файлах.
33. Проверка доступности регистрации учитывает флаг открытия регистрации и лимит команд.
34. Обрабатываются ошибки отсутствия файлов, некорректного JSON и неверных операций регистрации.
35. Логика разделена между `storage.py`, `utils.py`, `teams.py`, `submissions.py`, `statistics.py` и `main.py`.
36. В проекте применены коллекции, циклы, функции, импорт модулей, исключения, контекстные менеджеры и lambda-функции.
37. В ПР3 словари команд и проектов можно заменить классами и объектами.
38. Данные хранятся в файлах, чтобы они не исчезали после завершения программы и могли использоваться повторно.
