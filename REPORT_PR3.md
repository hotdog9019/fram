# Отчет по практической работе 3

## Индивидуальный проект

Название проекта: HackFlow

Предметная область: сервис для организации и проведения хакатона.

Основные классы: `Team`, `Hackathon`, `Submission`.

## Этапы выполнения

1. Сущности, которые ранее представлялись словарями в коллекциях, оформлены
   отдельными классами.
2. В классах реализованы `__init__`, атрибуты, методы поведения и `__str__`.
3. Хакатон связан с объектами команд. Сдача проекта связана с объектом команды.
   Перед созданием сдачи проверяется наличие команды на хакатоне и активный
   статус регистрации.
4. Методы `from_data()` и `to_data()` преобразуют JSON в объекты и объекты
   обратно в данные JSON.
5. Функции поиска, сортировки и статистики оставлены обычными функциями,
   поскольку работают с коллекциями объектов.
6. Обновлены тесты, README и проверка flake8. В данных представлены 5 команд,
   4 сдачи проектов и настройки хакатона.

Git-репозиторий: https://github.com/hotdog9019/fram

## Результат работы

Основные сущности представлены классами и объектами. Реализованы атрибуты и
методы, взаимодействие объектов, композиция, инкапсуляция и полиморфное
строковое представление через `__str__`. Существующая работа с коллекциями и
JSON адаптирована к объектной модели. Загрузка создает связанные объекты, а
сохранение записывает идентификаторы команд.

Автоматические тесты проверяют создание объектов, поиск, сортировку, расчет
организационного взноса, создание сдачи проекта, связь хакатона с командами,
связь сдачи с командой, определение финалистов, расчет статистики и сохранение
данных. Документация проекта обновлена.

## Вывод

В ходе ПР3 функциональная модель HackFlow была преобразована в
объектно-ориентированную. Данные и поведение объединены в классах, между
объектами организованы связи, а хранение в JSON и автоматическая проверка
проекта сохранены.
